HTTP API 端点

查询服务器和微信状态

响应示例：

{
  "status": "success",
  "wechat_running": true,
  "wechat_version": "4.0.0.x",
  "is_nt_version": true

发送文本消息给指定联系人

请求体：

{
  "contact_name": "文件传输助手",
  "message": "你好，这是一条测试消息"
}

响应示例：

{
  "status": "success",
  "message": "消息已发送",
  "delayed": false
}

MCP 协议端点

GET /mcp/sse
MCP over HTTP (Server-Sent Events) - 接收服务器推送的 MCP 响应

使用说明：

使用 EventSource API 连接此端点，服务器会推送 MCP 响应事件。

事件类型：

- mcp-response: MCP 响应数据
- mcp-error: MCP 错误信息
- keepalive: 心跳保活事件（每30秒）

JavaScript 示例：

const eventSource = new EventSource('/mcp/sse');
eventSource.addEventListener('mcp-response', (e) => {
  const response = JSON.parse(e.data);
  console.log(response);
});
POST /mcp/sse
MCP over HTTP (SSE) - 发送 MCP 请求到服务器

请求体：

{
  "jsonrpc": "2.0",
  "method": "initialize",
  "params": {
    "protocolVersion": "2024-11-05",
    "capabilities": {},
    "clientInfo": {
      "name": "web-client",
      "version": "1.0.0"
    }
  },
  "id": 1
}

响应：

HTTP 202 Accepted
响应会通过 GET /mcp/sse 推送
POST /mcp/stream
MCP over HTTP (NDJSON Streaming) - 发送并接收流式 MCP 消息

使用说明：

发送 NDJSON 格式的 MCP 请求（每行一个 JSON 对象），服务器返回 NDJSON 格式的响应。

请求示例：

{"jsonrpc":"2.0","method":"initialize","params":{...},"id":1}
{"jsonrpc":"2.0","method":"tools/list","id":2}

响应示例：

{"jsonrpc":"2.0","result":{...},"id":1}
{"jsonrpc":"2.0","result":{...},"id":2}
