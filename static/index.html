HTTP API 端点

GET /api/v1/status
查询服务器和微信状态

响应示例：

{
  "ok": true,
  "wechat_status": {
    "wechat_available": true,
    "wechat_version": "4.0.0.x",
    "is_nt_framework": true
  }
}
POST /api/v1/messages/send
发送文本消息给指定联系人

请求体：

{
  "contact_name": "文件传输助手",
  "message": "你好，这是一条测试消息"
}

响应示例：

{
  "ok": true,
  "message": "Message sent successfully"
}

MCP 协议端点

POST /mcp
MCP Streamable HTTP 端点 — 基于官方 MCP SDK (FastMCP)，支持完整的 MCP 协议交互

使用说明：

通过 POST 请求发送 JSON-RPC 格式的 MCP 消息。服务器返回带有 Mcp-Session-Id 头的响应，后续请求需携带该头以维持会话。

初始化请求示例：

{
  "jsonrpc": "2.0",
  "method": "initialize",
  "params": {
    "protocolVersion": "2024-11-05",
    "capabilities": {},
    "clientInfo": {
      "name": "web-client",
      "version": "1.0.0"
    }
  },
  "id": 1
}

工具调用示例：

{
  "jsonrpc": "2.0",
  "method": "tools/call",
  "params": {
    "name": "send_wechat_message",
    "arguments": {
      "contact_name": "文件传输助手",
      "message": "你好"
    }
  },
  "id": 2
}

可用工具：

- send_wechat_message: 向联系人发送文本消息
- schedule_wechat_message: 延迟发送消息
GET /mcp
MCP Streamable HTTP SSE 端点 — 用于接收服务器主动推送的通知（需携带 Mcp-Session-Id）

使用说明：

通过 GET 请求建立 SSE 连接，接收服务器端主动推送的通知和事件。请求头中需携带之前通过 POST 获取的 Mcp-Session-Id。

请求头：

Accept: text/event-stream
Mcp-Session-Id: <从 POST /mcp 响应获取>
DELETE /mcp
关闭 MCP 会话 — 通知服务器释放会话资源

请求头：

Mcp-Session-Id: <要关闭的会话 ID>
